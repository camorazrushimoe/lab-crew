# Skills Overview (v0.2)

Skills are implemented as `SKILL.md` files under each agent's `skills/` directory.

Legend: ✅ draft exists · ⏳ planned

## research-lead

| Skill | Purpose | Status |
|-------|---------|--------|
| `hypothesis-crafting` | Turn fuzzy ideas into sharp, testable hypotheses | ✅ |
| `research-briefing` | Write clear experiment briefs for Research Engineer | ✅ |
| `synthesis` | Produce Research Reports from experiment results | ✅ |
| `handoff` | Package findings for DevCrew | ✅ |
| `research-tracking` | Maintain hypotheses log and experiment status | ⏳ |

## research-engineer

| Skill | Purpose | Status |
|-------|---------|--------|
| `experiment-design` | Design the cheapest viable experiment | ✅ |
| `quick-parsing` | Lightweight parsers for research data sources | ✅ |
| `exploratory-analysis` | Basic EDA, tables, simple stats | ✅ |
| `data-collection` | Collect and organize temporary datasets | ⏳ |
| `reproducible-notes` | Leave scripts + notes others can audit/re-run | ⏳ |

## evaluation

| Skill | Purpose | Status |
|-------|---------|--------|
| `metric-design` | Choose metrics that match the research question | ✅ |
| `human-grading` | Design clear human grading protocols | ✅ |
| `evaluation-critique` | Find leakage, cherry-picking, other risks | ✅ |
| `auto-eval` | Design and implement automatic evaluation | ⏳ |
| `eval-reporting` | Write evaluation sections for the Research Report | ⏳ |
